# DeepSeek 大肥鱼 · 桌面桌宠 (DeepSeekPet)

<img src="docs/badge.png" width="140" align="right" alt="DeepSeek 大肥鱼">

一只趴在 Windows 桌面上的小蓝鱼桌宠。会自己溜达、被拎起来会拉长成史莱姆、单击她能看到你
DeepSeek 账户余额和"高峰/低谷"时段、把文件拖到她身上可以"喂"掉。

* **纯本地运行** —— 断网也能用,所有动画和交互都在本机。
* **唯一的联网点**是查余额时调一次 DeepSeek 官方**只读**接口( `/user/balance` ),
  用你自己的 API Key,**不消耗 token、不产生费用**。
* **不填 Key 也能用**,只是不显示余额。
* **自带清洁工** —— 每次启动自动清理历史残留垃圾,不给你的硬盘添堵(见下文)。

---

## 一、怎么用(免安装,解压即用)

1. 下载 **`DeepSeekPet-v1.0.3-win64-portable.zip`**,**整个解压到一个自己建的文件夹**里
   (例如 `D:\Apps\DeepSeekPet\`)。
   * ⚠️ **请整个文件夹一起用,别只把 `DeepSeekPet.exe` 单独拖出来** —— 她还需要旁边的
     `_internal\` 文件夹才能跑(和多数游戏一样:exe + 资源文件夹)。
   * 双击 `DeepSeekPet.exe` 即用,**不需要装 Python**。
2. 第一次启动会自动弹出**设置窗口**(圆角卡片那套界面)。
3. (可选)把 DeepSeek 的 API Key 粘进去 → 点「测试连接」确认 → 「保存并应用」。
   * 申请地址:<https://platform.deepseek.com> → API Keys → 创建。
   * Key 会加密后存在本机(Windows DPAPI,只有当前 Windows 用户能解开)。
4. 想开机自动出现 → 设置里打开「开机自启」那个滑块。

> 首次运行 Windows 可能弹 "SmartScreen 已阻止" —— 点「更多信息」→「仍要运行」即可
> (程序没做数字签名,自用/开源分发都没问题)。

### 操作一览

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 显示余额 + 高峰/低谷倒计时(没填 Key 会直接弹设置) |
| 左键拖动 | 把她拎走,松手会自己弹回去 |
| 右键 | 菜单:设置 / 看余额 / 弹一下 / 换一句 / 溜达开关 / 置顶 / 大小 / 退出 |
| 把文件拖到她身上 | "喂"掉文件(有确认框;默认丢进回收站,可改成彻底删除) |
| 双击气泡 | 收起气泡 |

> **她会"看心情"**:默认是**安静模式** —— 刚开机/被你点过之后先老实待着,冷落一会儿才自己溜达;
> 被你抓住拖走之后会安分更久。不想这样可以在设置里取消「安静模式」,或在右键菜单里关掉「溜达」。

### 置顶 & 全屏游戏

默认**置顶**,会压在普通窗口、浏览器上面;但**玩全屏游戏时会自动躲起来**,退出游戏又自己回来。
在设置里可以关掉「全屏游戏自动让位」,那样她就会一直压在最上面。

## 二、自带清洁工:不留垃圾在别人电脑上

这条值得单独说 —— 一个桌面小宠物,凭什么往你系统里留东西?

绝大多数打包成"单文件 exe"的程序都有个通病:运行时要把自己解压到系统临时目录(`%TEMP%`),
**正常退出会自己删,但一旦崩溃 / 被强杀 / 多开,这份解压出来的几十 MB 就永久留下了**。
用久了能堆出好几个 GB —— 而且用户完全不知道。

**本程序的做法:**

* 每次启动时,**自动扫描并清理** `%TEMP%` 下遗留的残渣目录(`_MEI*` 等);
* **只清该清的** —— 跳过自己正在用的目录,跳过 60 分钟内还在活动的目录(避免误删其他正在运行的程序);
* **失败静默** —— 清理出任何问题都绝不影响启动;
* 清理结果写进 `dspet.log`,你可以随时查它到底干了什么。

> 我们的观点:**"用完不留垃圾"应该是每个软件的默认行为,而不是需要用户手动去做的操作。**
> 如果你在做自己的软件,欢迎抄这个思路(实现见 `src/dspet/selfclean.py`)。

## 三、配置文件在哪

优先放在**程序同目录**的 `config.json`(便携、可整个文件夹拷走);如果那个目录不可写
(例如塞进了 `C:\Program Files`),会自动改用 `%APPDATA%\DeepSeekPet\config.json`。

同一目录下还会有 `dspet.log`(出问题时的日志)。

## 四、卸载

1. 设置里取消勾选「开机自启」(或手动删掉
   `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\DeepSeekPet.lnk`)。
2. 直接删掉整个程序文件夹(和 `%APPDATA%\DeepSeekPet`,如果有)。

> 干净卸载:程序不写注册表、不装驱动、不留后台服务。删掉文件夹它就没了。

## 五、系统要求

* Windows 10 / 11(x64)
* 免安装版无需 Python;源码运行需要 Python 3.10+ 和 `requirements.txt` 里的依赖

## 六、从源码运行 / 自己打包

```powershell
# 开发运行(控制台可见日志)
python run_dev.py --debug

# 打包:同时产出 单文件版 + 便携版(onedir,推荐分发)
powershell -ExecutionPolicy Bypass -File build\build.ps1 -Full
# 产物: dist\DeepSeekPet-v1.0.3-win64.exe          (单文件)
#       dist\DeepSeekPet-v1.0.3-win64-portable.zip (便携,推荐)
```

依赖:`pywin32`、`pillow`、`numpy`(numpy 只用于把位图快速转成半透明位图,没有会自动降级)。

> **分发建议**:便携版(onedir)启动更快、运行时不占 `%TEMP%`,是更稳的分发形态。
> 单文件版胜在"就一个文件",但每次运行会解包到临时目录(本程序会自动清理)。
